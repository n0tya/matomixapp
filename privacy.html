マトミクス プライバシーポリシー（下書き）

最終更新日: 2026-11-12

はじめに

マトミクス（以下「本アプリ」）は、利用者が入力した文章から、X（旧Twitter）などに投稿するための図解の画像を作るアプリです。本アプリの運営者（以下「運営者」）は、利用者の情報を次のとおり取り扱います。

1. 本アプリが扱う情報

  • 図解にするために利用者が入力した文章と出典（記事名や URL）
  • URL 読み込みを使ったときの、記事の URL
  • 利用者ごとに自動で作られる識別番号（匿名のログイン ID）
  • 1日に図解を作った回数・URL を読み込んだ回数と、プランの種類
  • 端末に保存される図解の履歴、色やブランド（ロゴの画像・名前）の設定

氏名、メールアドレス、電話番号の入力は求めません。アカウントの登録もありません。

2. 図解を作るときの文章の送信先

「図解にする」を押すと、入力した文章は運営者のサーバー（Google の Firebase。東京リージョン）を通して、Google の AI（Gemini API）に送られ、要点や数字の整理に使われます。図解の画像は、利用者の端末の中で作ります。

運営者は Gemini API を有料の契約で使っています。Google の規約では、有料の契約で送った内容は Google の製品の改善（AI の学習を含む）には使われません。ただし、不正利用の監視や法令への対応のために、Google が一定の期間保存することがあります。

運営者のサーバーは、送られた文章を保存しません。動作の記録（ログ）には、匿名のログイン ID、文字数、処理にかかった時間、使った AI の種類などを残しますが、文章の中身は残しません。

個人情報や、他の人に知られたくない内容は入力しないでください。

3. URL 読み込み

URL 読み込みを使うと、運営者のサーバーが、その URL のページを取りに行き、本文だけを取り出して利用者の端末に返します。取り出した本文は保存しません。動作の記録には、匿名のログイン ID、ページのドメイン名（例: example.com）、文字数を残します。

ログインが必要なページや、社内向けのアドレスのページは読み込みません。

4. 端末に保存する情報

図解の履歴（最大100件）、色やブランドの設定、同意の記録は、利用者の端末の中に保存します。運営者のサーバーには送りません。

端末の設定によっては、iPhone のバックアップ（iCloud など）にこれらが含まれることがあります。

図解を「写真に保存」したときや、ロゴの画像を選ぶときは、写真へのアクセスの許可を求めます。許可は端末の設定でいつでも取り消せます。

5. 利用目的

  • 図解を作り、利用者に表示するため
  • 1日に使える回数を数え、不正な使い方や、費用が想定を超えて膨らむことを防ぐため
  • 不具合を直し、本アプリを改善するため（動作の記録を使う。文章の中身は使わない）

6. 第三者への提供・広告

運営者は、上の 2・3 に書いた Google のサービスを使う場合と、法令に基づく場合を除き、利用者の情報を第三者に提供しません。

現在、本アプリは広告や、利用状況を分析するための外部サービスを使っていません。今後、有料プランの購入の仕組みや、これらのサービスを使う場合は、このポリシーを改定し、必要に応じて利用者の同意を得ます。

7. 情報の削除

図解の履歴は、本アプリの「履歴」からいつでも削除できます。本アプリを端末から削除した場合も、端末内の情報は削除されます（バックアップに残っている分を除く）。

運営者のサーバーにある回数の記録の削除を希望する場合は、下のお問い合わせ先に連絡してください。

8. ポリシーの変更

運営者は、必要に応じてこのポリシーを変更します。大事な変更をした場合は、本アプリの中でお知らせし、必要に応じて同意を取り直します。
