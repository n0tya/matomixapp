マトミクス プライバシーポリシー（下書き）

最終更新日: 2026-11-13

はじめに

マトミクス（以下「本アプリ」）は、利用者が入力した文章から、X（旧Twitter）などに投稿するための図解の画像を作るアプリです。本アプリの運営者（以下「運営者」）は、利用者の情報を次のとおり取り扱います。

1. 本アプリが扱う情報

  • 図解にするために利用者が入力した文章と出典（記事名や URL）
  • URL 読み込みを使ったときの、記事の URL
  • 利用者ごとに自動で作られる識別番号（匿名のログイン ID）
  • 1日に図解を作った回数・URL を読み込んだ回数と、プランの種類
  • 端末に保存される図解の履歴、色やブランド（ロゴの画像・名前）の設定、同意の記録

氏名、メールアドレス、電話番号の入力は求めません。アカウントの登録もありません。

2. 利用目的

  • 入力された文章から図解を作り、利用者に表示するため
  • 1日に使える回数を数え、不正な使い方や、費用が想定を超えて膨らむことを防ぐため
  • 不具合を直し、本アプリを改善するため（動作の記録を使う。文章の中身は使わない）
  • お問い合わせに答えるため

3. 図解を作るときの文章の送信先（外部の AI）

「図解にする」を押すと、入力した文章は運営者のサーバー（Google の Firebase。東京リージョン）を通して、Google LLC の AI（Gemini API）に送られ、要点や数字の整理に使われます。図解の画像は、利用者の端末の中で作ります。

運営者は、初めて本アプリを使うときの同意画面で、文章が Google の AI に送られることへの同意をいただいています。

運営者は Gemini API を有料の契約で使っています。Google の規約では、有料の契約で送った内容は Google の製品の改善（AI の学習を含む）には使われません。ただし、不正利用の監視や法令への対応のために、Google が一定の期間保存することがあります。

運営者のサーバーは、送られた文章を保存しません。

個人情報や、他の人に知られたくない内容は入力しないでください。

4. 外国にある事業者（Google）について

本アプリは、Google LLC（アメリカ合衆国）のサービス（Firebase・Gemini API）を使っています。文章や匿名のログイン ID などは、Google のサーバーで扱われ、日本以外の国で処理されることがあります。

  • 提供先の国: アメリカ合衆国（Google のサーバーがある国を含む）
  • その国の個人情報の保護に関する制度: 個人情報保護委員会が公表している情報（https://www.ppc.go.jp/enforcement/infoprovision/laws/offshore_report_america/）をご覧ください
  • Google が講じている措置: Google は、利用者のデータを保護するための安全管理措置を講じ、契約の範囲でのみデータを扱うことを定めています（Gemini API の規約・Google のプライバシーポリシー）。運営者は、Google が本ポリシーと同等以上の保護をするサービスであることを確認したうえで使っています

5. URL 読み込み

URL 読み込みを使うと、運営者のサーバーが、その URL のページを取りに行き、本文だけを取り出して利用者の端末に返します。取り出した本文は保存しません。

ログインが必要なページや、社内向けのアドレスのページは読み込みません。

6. 保存する場所と期間

  • 端末の中: 図解の履歴（最大100件）、色やブランドの設定、同意の記録。運営者のサーバーには送りません。本アプリを削除すると消えます（iPhone のバックアップに残っている分を除く）
  • 運営者のサーバー: 1日ごとの回数の記録（匿名のログイン ID・回数・プラン）。約30日で自動的に削除します
  • 動作の記録（ログ）: 匿名のログイン ID、文字数、処理にかかった時間、使った AI の種類、URL 読み込みのドメイン名（例: example.com）。文章の中身は残しません。約30日で自動的に削除されます
  • Google（Gemini API）: 上の 3 のとおり、不正利用の監視のために一定の期間保存されることがあります

図解を「写真に保存」したときや、ロゴの画像を選ぶときは、写真へのアクセスの許可を求めます。許可は端末の設定でいつでも取り消せます。

7. 第三者への提供・広告

運営者は、上の 3・4 に書いた Google のサービスを使う場合と、法令に基づく場合を除き、利用者の情報を第三者に提供しません。

現在、本アプリは広告や、利用状況を分析するための外部サービスを使っていません。今後、有料プランの購入の仕組みや、これらのサービスを使う場合は、このポリシーを改定し、必要に応じて利用者の同意を得ます。

8. 安全管理のための措置

  • 通信はすべて暗号化（HTTPS）しています
  • AI の API キーなどの秘密の情報は、Google Cloud の Secret Manager で管理し、アプリには入れていません
  • 運営者のデータベースは、アプリから直接読み書きできない設定にしています
  • 記録する情報は、本アプリの動作に必要な最小限にしています（文章の中身は残さない）
  • 外国（アメリカ合衆国）の事業者のサービスを使うため、上の 4 に書いた制度を確認したうえで使っています

9. 開示・削除などのご請求と、同意の取り消し

運営者のサーバーにある記録（回数の記録）について、開示・訂正・削除・利用の停止を希望する場合は、下のお問い合わせ先にメールでご連絡ください。本アプリの「設定」に表示される「あなたの ID」を添えてください。ご本人の端末の ID であることを確かめたうえで、遅滞なく対応します。

文章が Google の AI に送られることへの同意は、本アプリを使うのをやめ、端末から削除することで、いつでも取り消せます。すでに送られた文章の扱いは、上の 3 のとおりです。

図解の履歴は、本アプリの「履歴」からいつでも削除できます。

10. ポリシーの変更

運営者は、法令の変更や本アプリの機能の追加などに合わせて、このポリシーを変更することがあります。変更するときは、変更の内容と効力が生じる日を、効力が生じる日より前に、本アプリの中または紹介ページでお知らせします。大事な変更をした場合は、必要に応じて同意を取り直します。
